## 3. จุดที่ Spark พลาดเชิงกฎหมาย (สำคัญที่สุด)

Spark เสนอทางออกว่า "ถ้ายังไม่มีทะเบียน ให้แจกฟรีเป็นสารทดสอบในแปลงสาธิต" โดยถือว่าปลอดภัย
ข้อสังเกตของผม: นิยามคำว่า "ขาย" ใน พ.ร.บ.ปุ๋ย ครอบคลุมถึงการจำหน่าย จ่าย แจก แลกเปลี่ยน เพื่อประโยชน์ทางการค้า
การแจกสินค้าที่ยังไม่มีทะเบียนให้แปลงของ ศพก. โดยบริษัทผู้ผลิตเพื่อการค้า จึงอาจยังเข้าข่าย "ขาย" ได้
ต้องตรวจสอบกับ ศวพ.ชลบุรี หรือ สวพ.6 ก่อนว่ามีช่องทาง "ปุ๋ยเพื่อการทดลอง/วิจัย" อย่างเป็นทางการหรือไม่ และเงื่อนไขคืออะไร
ผมไม่ยืนยันข้อกฎหมายนี้ 100% แต่ความเสี่ยงสูงพอที่จะไม่ควรเดินตาม Spark โดยไม่ตรวจ

ผลต่อกลยุทธ์: ask เรื่องแปลงสาธิตยังเป็น hook ที่ดีที่สุด แต่ต้องเปลี่ยนจาก "เราจะเอาของไปลงแปลงเลย" เป็น "ขอให้เกษตรจังหวัดช่วยเชื่อมกับ ศวพ./สวพ.6 และ ศพก. เพื่อวางแผนทดสอบให้ถูกขั้นตอน" ซึ่งตรงกับเป้าหมายเรื่องการเชื่อมโยงของพี่พอดี

## 5. Keep / Cut / Fix สำหรับเอกสารฉัตร

Keep (ใช้ได้เกือบทันที)
- Module 2.2 ทำได้/ทำไม่ได้ ของเกษตรจังหวัด
- Module 2.3 ข้อห้ามของฉัตร (No Gift, ห้ามขอหนังสือเวียน, ห้ามเอารูปไปยิงแอด)
- Module 3.4 + 10.1 ask list โครงสร้างดี ปรับถ้อยคำ
- Deliverable D หมวดที่ 2 Objection handling 5 ข้อ คุณภาพดีที่สุดในรายงาน
- Deliverable C ส่วน "สิ่งที่ห้ามพูด" และ "สิ่งที่ต้องได้กลับบ้าน"
- Deliverable E โครงหนังสือแนะนำบริษัท (แก้ข้อเท็จจริง)
- Risk R01-R07

Cut (ไม่ตรงเป้าหมายใหม่)
- Module 4 ทั้งหมด (e-GP, SME-GP, MiT, บัญชีนวัตกรรม) เก็บไว้เป็น parking lot
- Module 6 ตารางคู่แข่ง (ของปลอมครึ่งหนึ่ง)
- Module 9.2 break-even (ราคาสมมติ)
- Milestone เรื่อง MiT/SME-GP ใน 60 วัน

Fix (ต้องแก้ก่อนใช้)
- Q&A ทุกข้อที่มีตัวเลขสินค้า ให้แทนด้วยข้อมูลจริงหรือถอดออก
- คำตอบ "มีทะเบียนไหม" ต้องตรงกับสถานะจริง ห้ามพูดว่า "กำลังยื่น" ถ้ายังไม่ได้ยื่น ให้พูดว่า "กำลังเตรียมยื่น" และบอกประเภทที่จะยื่น
- ตัดคำว่า "ลดปุ๋ยเคมี 20-30%" ออกจากทุกที่ จนกว่าจะมีข้อมูลแปลงจริง
- หนังสือแนะนำบริษัท: ลดคำบรรยายสรรพคุณสินค้า เพิ่มประโยค "ผลิตภัณฑ์อยู่ระหว่างดำเนินการขึ้นทะเบียนกับกรมวิชาการเกษตร" และเปลี่ยนข้อเสนอจาก "สนับสนุนผลิตภัณฑ์ฟรี" เป็น "ขอรับคำแนะนำในการวางแผนทดสอบร่วมกับหน่วยงานที่เกี่ยวข้อง"
- Factsheet: ตัดหัวข้อ 4 (ตัวเลขประโยชน์) และหัวข้อ 5 (อัตราใช้) ถ้าไม่มีข้อมูลรับรอง

## 6. กรอบใหม่ของการเข้าพบ (Cooperation-first)

เป้าหมายครั้งแรก: ให้เกษตรจังหวัดรู้จักบริษัทในฐานะผู้ประกอบการชลบุรีที่โปร่งใส และเปิดประตู 3 บาน
1. ประตูวิชาการ: referral ไป ศวพ.ชลบุรี / สวพ.6 เพื่อทำเรื่องทะเบียนและแผนทดสอบให้ถูกต้อง
2. ประตูเครือข่าย: รายชื่อกลุ่ม (ไม่ใช่รายบุคคล) ศพก. / แปลงใหญ่ / YSF / วิสาหกิจชุมชน ที่เปิดรับนวัตกรรม
3. ประตูเวที: ตารางงาน Field Day / งานเกษตรจังหวัด / เวทีอบรม ที่เอกชนร่วมให้ความรู้ได้

Ask list 5 ข้อ (ปรับจาก Spark)
1. ขอคำแนะนำว่าพืชและพื้นที่ใดในชลบุรีที่จังหวัดกำลังเน้นเรื่องลดต้นทุนและฟื้นฟูดิน
2. ขอให้ช่วยแนะนำการประสานงานกับ ศวพ./สวพ.6 เรื่องขึ้นทะเบียนและการทดสอบ
3. ขอรายชื่อ ศพก. / แปลงใหญ่ / กลุ่ม YSF ที่สนใจร่วมแปลงเรียนรู้ เมื่อสินค้าพร้อมตามระเบียบ
4. ขอทราบปฏิทิน Field Day และเวทีที่เอกชนร่วมให้ความรู้ได้ และขั้นตอนการขอเข้าร่วม
5. ขอนัดรายงานความคืบหน้าใน 60 วัน

## 7. คำถามที่ยังต้องการคำตอบจากพี่นอร์ท
1. สถานะทะเบียนจริง: ยังไม่เริ่ม / เตรียมเอกสาร / ยื่นแล้ว และตั้งใจยื่นประเภทไหน
2. ข้อมูลสินค้าที่ยืนยันได้: วัตถุดิบ ส่วนประกอบ ผลแล็บ ที่ตั้งบริษัท
3. หลักฐานการใช้จริงกับพืชในภาคตะวันออก (พืชอะไร ผลเป็นอย่างไร มีรูปไหม)
4. ฉัตรรู้เรื่องสถานะ "อาหารเสริมพืช" และข้อจำกัดการพูดแล้วหรือยัง
