# RESEARCH MODULES (ต้องทำครบทั้ง 12 module)

## Module 1: Regulatory & Compliance (ทำก่อน เพราะเป็นตัวกำหนดว่า module อื่นเป็นไปได้หรือไม่)

1.1 พ.ร.บ.ปุ๋ย พ.ศ. 2518 และฉบับแก้ไขเพิ่มเติม รวมถึงประกาศกระทรวงเกษตรฯ และประกาศกรมวิชาการเกษตรที่เกี่ยวข้อง ตอบให้ชัด:
   - นิยามและการจำแนกประเภทปุ๋ยตามกฎหมายไทยในปัจจุบัน (ปุ๋ยเคมี ปุ๋ยอินทรีย์ ปุ๋ยชีวภาพ ปุ๋ยอินทรีย์เคมี และประเภทย่อยอื่น)
   - ผลิตภัณฑ์กลุ่มกรดอะมิโน (amino acid based fertilizer / biostimulant) จัดอยู่ประเภทใดตามกฎหมายไทย มีเงื่อนไขการขึ้นทะเบียนอย่างไร มีตัวอย่างผลิตภัณฑ์กรดอะมิโนที่ขึ้นทะเบียนแล้วในฐานข้อมูลกรมวิชาการเกษตรหรือไม่ (ค้นในระบบสืบค้นทะเบียนปุ๋ยของกรมวิชาการเกษตร) ระบุประเภทที่ผลิตภัณฑ์เหล่านั้นใช้
   - ประเทศไทยมีหมวดหมู่ "biostimulant" หรือ "สารเสริมประสิทธิภาพพืช" แยกต่างหากในกฎหมายหรือไม่ ณ ปัจจุบัน มีร่างกฎหมายหรือประกาศใหม่ที่กำลังจะออกหรือไม่
   - ใบอนุญาตที่ผู้ผลิต ผู้ขาย และตัวแทนจำหน่ายต้องมี (ใบอนุญาตผลิตปุ๋ยเพื่อการค้า ใบอนุญาตขายปุ๋ย ฯลฯ) ค่าธรรมเนียม อายุใบอนุญาต หน่วยงานที่ออก (กรมวิชาการเกษตรส่วนกลาง หรือ สำนักวิจัยและพัฒนาการเกษตรเขต / ศูนย์วิจัยและพัฒนาการเกษตรจังหวัด) และขั้นตอนขอ ระบุให้ชัดว่า "ฉัตร" ในฐานะตัวแทนจำหน่ายต้องมีใบอนุญาตขายปุ๋ยเป็นของตัวเองหรือไม่
   - ข้อกำหนดฉลาก และข้อห้ามเรื่องการโฆษณาอ้างสรรพคุณ บทลงโทษเมื่อฝ่าฝืน (ระบุมาตราและโทษ)
1.2 ถ้าผลิตภัณฑ์มีจุลินทรีย์หรือสารออกฤทธิ์ที่อาจเข้าข่าย พ.ร.บ.วัตถุอันตราย พ.ศ. 2535 ให้ตรวจสอบเส้นแบ่งและความเสี่ยงที่จะถูกตีความว่าเป็นวัตถุอันตรายทางการเกษตร
1.3 มาตรฐานและการรับรองที่เพิ่มความน่าเชื่อถือกับหน่วยงานรัฐ: มาตรฐานสินค้าเกษตร (มกษ.) ที่เกี่ยวข้อง, Organic Thailand, IFOAM, มาตรฐานโรงงาน (GMP/ISO), ผลวิเคราะห์จากห้องปฏิบัติการที่กรมวิชาการเกษตรยอมรับ ระบุว่าอันไหน "จำเป็น" อันไหน "เพิ่มแต้มต่อ" และต้นทุน/ระยะเวลาโดยประมาณ (ถ้ามีข้อมูล)
1.4 สรุปเป็นตาราง Compliance Gap: สิ่งที่กฎหมายกำหนด vs สถานะปัจจุบันของบริษัท (ตาม CONTEXT) vs ความเสี่ยงถ้าเข้าพบหน่วยงานรัฐโดยยังไม่ครบ vs สิ่งที่ต้องทำก่อนวันศุกร์ (ถ้าทำได้) หรือต้องพูดอย่างไรในที่ประชุมถ้ายังไม่ครบ

## Module 2: โครงสร้าง อำนาจหน้าที่ และข้อจำกัดของสำนักงานเกษตรจังหวัด

2.1 โครงสร้างของกรมส่งเสริมการเกษตร ตั้งแต่ส่วนกลาง สำนักงานส่งเสริมและพัฒนาการเกษตรเขต สำนักงานเกษตรจังหวัด สำนักงานเกษตรอำเภอ จนถึงเกษตรตำบล ระบุกลุ่มงานภายในสำนักงานเกษตรจังหวัดทั้งหมด (เช่น กลุ่มยุทธศาสตร์และสารสนเทศ กลุ่มส่งเสริมและพัฒนาการผลิต กลุ่มส่งเสริมและพัฒนาเกษตรกร กลุ่มอารักขาพืช ฝ่ายบริหารทั่วไป หรือชื่อที่ถูกต้องในปัจจุบัน) และหน้าที่ของแต่ละกลุ่ม พร้อมวิเคราะห์ว่ากลุ่มใดเกี่ยวข้องกับสินค้า Amino Go มากที่สุดและควรขอพบใคร (ระบุตำแหน่ง ไม่ระบุชื่อ)
2.2 ตอบตรงๆ: สำนักงานเกษตรจังหวัด "มีอำนาจซื้อปุ๋ยแจกเกษตรกร" หรือไม่ ปกติทำในกรณีใดบ้าง (เช่น ภัยพิบัติ โครงการตามนโยบาย งบจังหวัด) และ "ไม่มีอำนาจทำอะไร" (เช่น รับรองผลิตภัณฑ์ แนะนำยี่ห้อเฉพาะให้เกษตรกร) เพื่อให้ผู้ว่าจ้างไม่ตั้งความหวังผิดจุด
2.3 ระเบียบ/แนวปฏิบัติของราชการเกี่ยวกับการทำงานร่วมกับภาคเอกชน: การรับสนับสนุนสินค้าหรือของขวัญ (ประกาศ ป.ป.ช. เรื่องการรับทรัพย์สินหรือประโยชน์อื่นใด ระบุวงเงินและเงื่อนไขปัจจุบัน) การให้เอกชนใช้พื้นที่หรือเวทีของรัฐ การใส่ชื่อบริษัทในเอกสารราชการ ผลประโยชน์ทับซ้อน สิ่งที่ฉัตร "ห้ามทำเด็ดขาด" ในการเข้าพบและหลังการเข้าพบ
2.4 หน่วยงานภาครัฐอื่นในระดับจังหวัดที่อาจเป็นประตูที่ตรงกว่าหรือเสริมกัน พร้อมเหตุผลและอำนาจหน้าที่ของแต่ละหน่วย: ศูนย์วิจัยและพัฒนาการเกษตรจังหวัด/สวพ.เขต (กรมวิชาการเกษตร), สถานีพัฒนาที่ดินจังหวัด (กรมพัฒนาที่ดิน) และเครือข่ายหมอดินอาสา, สำนักงานสหกรณ์จังหวัด (กรมส่งเสริมสหกรณ์), ธ.ก.ส. สาขาในพื้นที่, สภาเกษตรกรจังหวัด, สำนักงานพาณิชย์จังหวัด, สำนักงานอุตสาหกรรมจังหวัด, ศูนย์ส่งเสริมอุตสาหกรรมภาค (กรมส่งเสริมอุตสาหกรรม), ศูนย์ให้บริการ SME ครบวงจร (สสว.), สำนักงานเกษตรและสหกรณ์จังหวัด, องค์การบริหารส่วนจังหวัด/อบต. (งบท้องถิ่นด้านเกษตร), มหาวิทยาลัยหรือวิทยาลัยเกษตรในพื้นที่ จัดลำดับความสำคัญของหน่วยงานเหล่านี้สำหรับบริษัท และแนะนำว่าควรขอให้เกษตรจังหวัดช่วยแนะนำต่อ (referral) ไปหน่วยไหน

## Module 3: โครงการ งบประมาณ และปฏิทินของภาครัฐที่บริษัทเกาะได้

3.1 รวบรวมโครงการของกรมส่งเสริมการเกษตรและกระทรวงเกษตรฯ ที่ยัง active ในปีงบประมาณ 2569 และที่ประกาศแล้วสำหรับปีงบประมาณ 2570 ที่มีจุดเชื่อมกับปัจจัยการผลิต การลดต้นทุน หรือการเพิ่มคุณภาพผลผลิต อย่างน้อยให้ตรวจสอบสถานะปัจจุบันของ: ระบบส่งเสริมเกษตรแบบแปลงใหญ่, ศูนย์เรียนรู้การเพิ่มประสิทธิภาพการผลิตสินค้าเกษตร (ศพก.), ศูนย์จัดการดินปุ๋ยชุมชน (ศดปช.), โครงการส่งเสริมการใช้ปุ๋ยตามค่าวิเคราะห์ดิน / ปุ๋ยสั่งตัด, Smart Farmer และ Young Smart Farmer, วิสาหกิจชุมชน, โครงการเกษตรอินทรีย์และ BCG, โครงการลดต้นทุนการผลิตข้าวหรือพืชหลักของจังหวัด, โครงการช่วยเหลือปัจจัยการผลิตแบบร่วมจ่าย (เช่น โครงการที่เคยเรียกว่า "ปุ๋ยคนละครึ่ง" ให้ตรวจว่ายกเลิก แทนที่ หรือมีเวอร์ชันใหม่หรือไม่), งานวันถ่ายทอดเทคโนโลยี (Field Day), ตลาดเกษตรกร, โครงการอาสาสมัครเกษตรหมู่บ้าน (อกม.), โครงการอื่นที่พบ สำหรับแต่ละโครงการระบุ: วัตถุประสงค์ กลุ่มเป้าหมาย งบประมาณ (ถ้าเปิดเผย) วิธีที่เอกชนเข้าไปมีส่วนร่วมได้ (ถ้ามี) และแหล่งอ้างอิง
3.2 งบพัฒนาจังหวัดและกลุ่มจังหวัด: ค้นแผนพัฒนาจังหวัด [จังหวัด] ฉบับล่าสุด และแผนปฏิบัติราชการประจำปี ระบุยุทธศาสตร์/โครงการด้านเกษตรที่มีงบประมาณ และหน่วยงานเจ้าภาพ วิเคราะห์ว่า Amino Go เข้าได้กับโครงการไหน
3.3 ปฏิทินราชการที่กระทบจังหวะการติดต่อ: ปีงบประมาณ วงจรการทำแผนและคำของบประมาณ (ตอนนี้กำลังทำแผนของปีใด) ช่วงเวลาที่ข้าราชการมีภาระปิดงบ ฤดูกาลเพาะปลูกของพืชหลักใน [จังหวัด] และงานประจำปี/งานเกษตรของจังหวัดที่บริษัทควรไปออกบูธ ให้ทำเป็น timeline 12 เดือนข้างหน้า
3.4 การเข้าถึง "เครือข่ายที่รัฐดูแล" โดยไม่ต้องผ่านการจัดซื้อ: กลุ่มแปลงใหญ่ใน [จังหวัด] (จำนวนกลุ่ม พืช ขนาดพื้นที่ ถ้ามีข้อมูลสาธารณะ), รายชื่อ ศพก. และ ศดปช. ในจังหวัด, วิสาหกิจชุมชนด้านเกษตรที่จดทะเบียน, กลุ่ม YSF ของจังหวัด ระบุว่าข้อมูลใดเปิดเผยสาธารณะและข้อมูลใดต้องขอจากเกษตรจังหวัด (ซึ่งเป็น ask ที่ดีในที่ประชุม)

## Module 4: เส้นทางเข้าสู่ระบบจัดซื้อจัดจ้างและ Preference ของภาครัฐ

4.1 พ.ร.บ.การจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560 และกฎกระทรวงที่เกี่ยวข้อง: วิธีการจัดซื้อ (เฉพาะเจาะจง คัดเลือก e-bidding) วงเงินของแต่ละวิธีในปัจจุบัน (ตรวจสอบตัวเลขล่าสุด) และผลิตภัณฑ์ปุ๋ย/ปัจจัยการผลิตมักถูกจัดซื้อผ่านวิธีใด
4.2 ขั้นตอนลงทะเบียนผู้ค้ากับภาครัฐในระบบ e-GP เอกสารที่ใช้ ระยะเวลา ค่าใช้จ่าย
4.3 มาตรการแต้มต่อสำหรับ SME: การขึ้นทะเบียน THAI SME-GP กับ สสว. สิทธิประโยชน์ (สัดส่วนที่หน่วยงานรัฐต้องซื้อจาก SME, แต้มต่อด้านราคา) เงื่อนไขและวิธีสมัคร ตรวจสอบว่ามาตรการยังมีผลในปีงบประมาณ 2570
4.4 Made in Thailand (MiT) โดยสภาอุตสาหกรรมแห่งประเทศไทย: สิทธิประโยชน์ในการจัดซื้อภาครัฐ เงื่อนไข ค่าใช้จ่าย ระยะเวลา
4.5 บัญชีนวัตกรรมไทย: เงื่อนไขการขึ้นบัญชี (ต้องมีงานวิจัยร่วมกับหน่วยงานไทย ผ่านการทดสอบ ฯลฯ) ประโยชน์ (หน่วยงานรัฐจัดซื้อได้โดยวิธีเฉพาะเจาะจง) ระยะเวลาและความยากง่าย มีผลิตภัณฑ์ปุ๋ยหรือชีวภัณฑ์ที่อยู่ในบัญชีนี้แล้วหรือไม่ ยกตัวอย่างพร้อมแหล่งอ้างอิง เพื่อประเมินว่า Amino Go จะเดินเส้นทางนี้ได้ไหมและใช้เวลาเท่าไร
4.6 ช่องทางกึ่งรัฐ: ธ.ก.ส. (โครงการสินเชื่อปัจจัยการผลิต ร้านค้าหรือแพลตฟอร์มที่ ธ.ก.ส. สนับสนุน เงื่อนไขการเป็นร้านค้า/ผู้จำหน่ายในเครือข่าย), สหกรณ์การเกษตร (วิธีที่สหกรณ์จัดหาปัจจัยการผลิตมาขายสมาชิก ใครเป็นผู้ตัดสินใจ ต้องผ่านมติกรรมการหรือไม่ margin ที่สหกรณ์ต้องการ), องค์การตลาดเพื่อเกษตรกร (อ.ต.ก.), ร้าน Q Shop / ร้านจำหน่ายปัจจัยการผลิตที่ได้รับการรับรอง
4.7 สรุปเป็นตาราง: ช่องทาง | เงื่อนไขเข้า | ระยะเวลา | ต้นทุน | โอกาสสำเร็จสำหรับบริษัทขนาดเล็ก | สิ่งที่เกษตรจังหวัดช่วยได้ในช่องทางนั้น | ลำดับที่แนะนำ

## Module 5: Area Intelligence ของ [จังหวัด]

5.1 ข้อมูลพื้นฐานการเกษตรของจังหวัด: พืชเศรษฐกิจหลัก 5 อันดับ พื้นที่ปลูก จำนวนเกษตรกรที่ขึ้นทะเบียน ผลผลิตต่อไร่เทียบค่าเฉลี่ยประเทศ ปัญหาดิน/โรค/ต้นทุนที่เกษตรกรในจังหวัดเผชิญ (ใช้ข้อมูลจากสำนักงานเศรษฐกิจการเกษตร สำนักงานเกษตรจังหวัด และแผนพัฒนาจังหวัด)
5.2 จับคู่ Amino Go กับพืชและปัญหาของจังหวัด: พืชใดที่กรดอะมิโนมีหลักฐานว่าช่วยได้และเป็นพืชหลักของจังหวัด ให้เรียงลำดับโอกาส
5.3 โครงสร้างตลาดปัจจัยการผลิตในจังหวัด: จำนวนร้านค้าปุ๋ยโดยประมาณ ผู้ค้าส่งรายใหญ่ สหกรณ์ที่มีธุรกิจจัดหาปัจจัยการผลิต (ถ้ามีข้อมูลสาธารณะ) ราคาปุ๋ยเคมีและสารเสริมที่เกษตรกรจ่ายอยู่
5.4 คู่แข่งที่มีตัวตนในจังหวัด: แบรนด์กรดอะมิโน/biostimulant ที่ทำตลาดในพื้นที่ (จากร้านค้า, เพจ, งานเกษตรจังหวัด) และมีรายใดที่เคยร่วมโครงการกับหน่วยงานรัฐในจังหวัดนี้หรือไม่
5.5 ข่าวและนโยบายล่าสุดของจังหวัดที่เกี่ยวข้อง 12 เดือนย้อนหลัง: ภัยแล้ง น้ำท่วม โรคระบาด นโยบายผู้ว่าราชการจังหวัดด้านเกษตร ซึ่งใช้เป็น talking point ในที่ประชุม

## Module 6: Category & Competitor Landscape ระดับประเทศ

6.1 ตลาดปุ๋ยกรดอะมิโนและ biostimulant ในไทย: ขนาดตลาดโดยประมาณ (ระบุแหล่งและปี) แนวโน้มการเติบโต ปัจจัยขับเคลื่อน (ราคาปุ๋ยเคมี นโยบายลดสารเคมี BCG เกษตรอินทรีย์ คาร์บอนเครดิตภาคเกษตร)
6.2 คู่แข่งหลัก 8-12 ราย ทั้งบริษัทไทยและต่างชาติ: ชื่อผลิตภัณฑ์ ส่วนประกอบ ราคาต่อหน่วยและต่อไร่ ประเภททะเบียนที่ใช้ ช่องทางจำหน่าย จุดขาย และมีความสัมพันธ์กับภาครัฐอย่างไร (เคยเป็นผู้จำหน่ายในโครงการรัฐ เคยทำแปลงสาธิตกับกรม ฯลฯ) ทำเป็นตารางเปรียบเทียบ และวาง Amino Go ลงในตารางเดียวกัน (ใช้ข้อมูลจาก CONTEXT)
6.3 วิเคราะห์ positioning gap: บริษัทเล็กจะชนะรายใหญ่ในสายตาหน่วยงานรัฐได้ด้วยอะไร (ความเป็นท้องถิ่น ราคา หลักฐาน การบริการ การอบรม)

## Module 7: Scientific Evidence & Demo Plot Design

7.1 รวบรวมงานวิจัยที่เชื่อถือได้เกี่ยวกับประสิทธิภาพของกรดอะมิโนทางใบ/ทางดินต่อพืชเป้าหมาย (ตาม CONTEXT และพืชหลักของจังหวัด) โดยให้ความสำคัญกับงานวิจัยของสถาบันไทย (มหาวิทยาลัยเกษตรศาสตร์ แม่โจ้ ขอนแก่น เชียงใหม่ กรมวิชาการเกษตร ฯลฯ) และ meta-analysis ระดับสากล ระบุ: พืช ปริมาณ วิธีใช้ ผลที่วัดได้ (ผลผลิต คุณภาพ ความทนทานต่อความเครียด) และข้อจำกัด ให้ระบุด้วยว่างานใดพบว่า "ไม่มีผล" เพื่อความเป็นธรรม
7.2 หน่วยงานรัฐยอมรับหลักฐานแบบใด: รูปแบบผลทดสอบที่กรมวิชาการเกษตรหรือกรมส่งเสริมการเกษตรใช้ประกอบการพิจารณา (การทดสอบประสิทธิภาพ แปลงเปรียบเทียบ ค่าสถิติ) และเงื่อนไขการอ้างอิงผลทดสอบในเอกสารทางการตลาด
7.3 ออกแบบข้อเสนอแปลงสาธิตร่วมกับสำนักงานเกษตรจังหวัด/ศพก./แปลงใหญ่: protocol อย่างง่ายที่น่าเชื่อถือ (control vs treatment, จำนวนซ้ำ, ตัวชี้วัด, ระยะเวลา, ใครเก็บข้อมูล, ต้นทุนที่บริษัทต้องออก, สิ่งที่รัฐออกได้), ตัวอย่างร่าง MOU หรือบันทึกความร่วมมือที่หน่วยงานรัฐเคยทำกับเอกชน (ค้นตัวอย่างจริงพร้อมแหล่งอ้างอิง)

## Module 8: Partnership & Business Models กับภาครัฐและเครือข่ายเกษตรกร

เสนออย่างน้อย 5 โมเดล เช่น (a) แปลงสาธิตร่วมกับ ศพก./แปลงใหญ่ แล้วต่อยอดเป็นการขายตรงให้สมาชิกกลุ่ม (b) เป็นวิทยากร/ผู้สนับสนุนในงานอบรมของสำนักงานเกษตรจังหวัดโดยไม่ขายในงาน (c) ผ่านสหกรณ์การเกษตรเป็นผู้จัดจำหน่าย (d) ผ่านเครือข่าย YSF หรือ อกม. เป็น sub-dealer (e) เข้าสู่โครงการงบจังหวัดผ่านการเป็นผู้ค้าที่ขึ้นทะเบียน (f) ทำงานกับสถานีพัฒนาที่ดินและหมอดินอาสาเรื่องการปรับปรุงดิน (g) ร่วมกับมหาวิทยาลัยในพื้นที่ทำวิจัยเพื่อเข้าบัญชีนวัตกรรมไทย
สำหรับแต่ละโมเดลระบุ: ขั้นตอน ผู้มีอำนาจตัดสินใจ ระยะเวลาถึงรายได้ครั้งแรก ต้นทุน ความเสี่ยง (รวมกฎหมายและภาพลักษณ์) precedent จริงที่บริษัทอื่นเคยทำ (พร้อมแหล่งอ้างอิง ถ้าไม่มีให้บอกว่าไม่พบ) และเงื่อนไขที่โมเดลนั้นดีที่สุด
ปิดด้วยตารางเปรียบเทียบและคำแนะนำว่าควรเสนออะไรในที่ประชุมวันศุกร์ (ควรเสนอไม่เกิน 2 โมเดลเพื่อไม่ให้กระจาย)

## Module 9: โมเดลรายได้และสถานะทางกฎหมายของ "ฉัตร" ในฐานะตัวแทนจำหน่าย

9.1 เปรียบเทียบรูปแบบความสัมพันธ์: ตัวแทนจำหน่ายอิสระ (ซื้อขาด) / นายหน้ารับค่าคอมมิชชั่น / พนักงานขายของบริษัท / ตัวแทนช่วงในระบบขายตรง ในมิติ: ภาษี (ภาษีเงินได้บุคคลธรรมดา, หัก ณ ที่จ่าย, VAT), ประกันสังคม, ใบอนุญาตขายปุ๋ยที่ต้องมี, ความรับผิดต่อลูกค้า, สัญญาที่ควรทำ, การควบคุมราคาและพื้นที่ (territory)
9.2 โครงสร้างค่าตอบแทนที่ใช้กันในตลาดปัจจัยการผลิตไทย: margin ของร้านค้า/ตัวแทน/ผู้ค้าส่งโดยประมาณ (ระบุแหล่งหรือบอกว่าเป็นค่าประมาณจากอุตสาหกรรม) และเสนอโครงสร้าง 2-3 แบบสำหรับฉัตร พร้อม break-even (ต้องขายกี่หน่วยต่อเดือนถึงจะได้รายได้เป้าหมาย [ระบุเป้ารายได้ของฉัตร ถ้าไม่ระบุให้ทำ 3 ระดับ])
9.3 ถ้าบริษัทจะทำระบบขายตรง: พ.ร.บ.ขายตรงและตลาดแบบตรง พ.ศ. 2545 และฉบับแก้ไข การจดทะเบียนกับ สคบ. เงื่อนไข ค่าใช้จ่าย ข้อห้าม (แชร์ลูกโซ่) และผลกระทบต่อภาพลักษณ์เมื่อติดต่อกับหน่วยงานรัฐ ให้ประเมินว่าควรพูดเรื่องนี้ในที่ประชุมกับเกษตรจังหวัดหรือไม่
9.4 PDPA (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562): ถ้าฉัตรเก็บชื่อ เบอร์โทร พิกัดแปลง ของเกษตรกรจากการลงพื้นที่หรือได้รายชื่อจากหน่วยงานรัฐ ต้องทำอะไรบ้าง (privacy notice, ฐานทางกฎหมาย, การเก็บรักษา) และหน่วยงานรัฐให้รายชื่อเกษตรกรกับเอกชนได้หรือไม่ตามกฎหมาย
9.5 Conflict of interest ภายในครอบครัว: ประเด็นที่ควรตกลงล่วงหน้าระหว่างเจ้าของบริษัทกับน้องชาย (พื้นที่ ราคา เครดิต การคืนสินค้า สิทธิ์ในลูกค้า การเลิกสัญญา) เพื่อรักษาความสัมพันธ์ระยะยาว

## Module 10: Meeting Preparation Package สำหรับวันศุกร์

10.1 วัตถุประสงค์ของการเข้าพบที่ realistic สำหรับครั้งแรก (ควรตั้งเป้าที่ "ความสัมพันธ์และข้อมูล" ไม่ใช่ "ยอดขาย") และ ask list ที่ชัดเจน 5-7 ข้อ เรียงตามความยากง่าย เช่น ขอข้อมูลกลุ่มแปลงใหญ่/ศดปช., ขอโอกาสร่วมงาน Field Day, ขอคำแนะนำหน่วยงานที่ควรติดต่อต่อ, ขอเสนอแปลงสาธิต, ขอเข้าร่วมประชุมเครือข่าย
10.2 คำถามที่เจ้าหน้าที่จะถามและคำตอบที่ควรเตรียม อย่างน้อย 20 ข้อ ครอบคลุม: ทะเบียนปุ๋ย ส่วนประกอบ ผลทดสอบ ราคาเทียบต้นทุนที่เกษตรกรประหยัดได้ ความปลอดภัย ความแตกต่างจากคู่แข่ง กำลังการผลิต บริการหลังการขาย และ "ทำไมต้องคุยกับสำนักงานเกษตรจังหวัด" สำหรับคำตอบใดที่ขึ้นกับข้อมูลที่ผู้ว่าจ้างยังไม่ให้ ให้ใส่ช่อง [ ] ให้กรอก
10.3 Objection handling: ข้อโต้แย้งที่พบบ่อยจากข้าราชการ (ไม่มีอำนาจ, ต้องเป็นกลางเรื่องยี่ห้อ, งบไม่มี, ต้องมีผลวิจัย, เคยมีเอกชนมาแล้วหาย) พร้อมวิธีตอบที่ให้เกียรติและเปิดประตูต่อ
10.4 มารยาทและ protocol ราชการ: การนัดหมายล่วงหน้า การแต่งกาย การแนะนำตัว เอกสารที่ควรยื่น (หนังสือแนะนำบริษัท) การติดตามผลหลังพบ (หนังสือขอบคุณ, ระยะเวลาที่เหมาะสมในการติดตาม) และสิ่งที่ห้ามทำ (ตาม Module 2.3)
10.5 รายการเอกสารที่ฉัตรควรถือไป: จัดเป็น 3 ชั้น (ต้องมี / ควรมี / มีก็ดี) พร้อมระบุว่าแต่ละชิ้นตอบคำถามอะไรของเจ้าหน้าที่ และชิ้นใดที่ยังไม่มีควรสร้างก่อนวันศุกร์
10.6 ร่างเนื้อหา Company & Product One-Pager (ภาษาราชการ สุภาพ ไม่โฆษณาเกินจริง ไม่อ้างสรรพคุณที่กฎหมายห้าม) และร่างหนังสือแนะนำบริษัทแบบทางการ ความยาวไม่เกิน 1 หน้า

## Module 11: Risk Register (Strategy / Operations / Legal / Reputation / PDPA)

ทำตาราง risk register อย่างน้อย 15 รายการ: ความเสี่ยง | สาเหตุ | โอกาสเกิด (สูง/กลาง/ต่ำ) | ผลกระทบ | สัญญาณเตือน | มาตรการป้องกัน | ใครรับผิดชอบ | ต้องปิดก่อนวันศุกร์หรือไม่
ครอบคลุมอย่างน้อย: ขายปุ๋ยโดยทะเบียน/ใบอนุญาตไม่ครบ, โฆษณาเกินจริง, ถูกตีความว่าให้ประโยชน์เจ้าหน้าที่, พึ่งพิงงบรัฐที่ไม่แน่นอน, การถูกลอกสูตรหรือถูกคู่แข่งใหญ่ตัดราคาเมื่อเข้าโครงการรัฐ, ความรับผิดต่อความเสียหายของพืช (product liability) และการทำประกัน, PDPA จากรายชื่อเกษตรกร, ความขัดแย้งในครอบครัวจากผลประโยชน์, ความเสี่ยงที่ฉัตรพูดเกินขอบเขตอำนาจ, ความเสี่ยงด้าน cash flow ถ้ารัฐจ่ายช้า (เครดิตเทอมของภาครัฐ), ความเสี่ยงต่อภาพลักษณ์ถ้าเปิดเรื่องขายตรงในบริบทราชการ

## Module 12: Roadmap และ Decision Framework

12.1 แผน 7 วัน (ก่อนวันศุกร์): สิ่งที่ต้องทำเรียงตามวัน
12.2 แผน 30 / 60 / 90 วันหลังการเข้าพบ: milestone, ตัวชี้วัด, จุดตัดสินใจ (go / no-go) ของแต่ละช่องทางที่แนะนำ
12.3 Decision framework สำหรับผู้ว่าจ้าง: ทางเลือกเชิงกลยุทธ์ 3-4 ทาง (เช่น "รัฐเป็นช่องทางหลัก" / "รัฐเป็นตัวสร้างความน่าเชื่อถือ แต่ขายผ่านเอกชน" / "ไม่ลงทุนกับรัฐ โฟกัส Facebook และร้านค้า") พร้อมข้อดี ข้อเสีย เงื่อนไขที่ทางเลือกนั้นดีที่สุด และคำแนะนำของคุณพร้อมเหตุผล และระบุว่า "ข้อมูลใดจากที่ประชุมวันศุกร์ที่จะทำให้คำแนะนำเปลี่ยน"

# OUTPUT SPECIFICATION (ต้องส่งครบทุก deliverable)

Deliverable A: Executive Summary ไม่เกิน 1 หน้า ตอบ 4 คำถามใน OBJECTIVE ตรงๆ พร้อม top 5 findings และ top 3 risks
Deliverable B: Full Research Report เรียงตาม Module 1-12 ทุก finding ติดป้าย [FACT]/[INFERENCE]/[ASSUMPTION] และมีแหล่งอ้างอิงแบบ inline (ชื่อเอกสาร, หน่วยงาน, URL, วันที่)
Deliverable C: Meeting Brief สำหรับฉัตร ไม่เกิน 2 หน้า ภาษาง่าย อ่านจบใน 10 นาที ประกอบด้วย: เป้าหมายการพบ, ask list, 10 คำถามที่จะโดนถามพร้อมคำตอบสั้น, สิ่งที่ห้ามพูด/ห้ามทำ, สิ่งที่ต้องได้กลับมา (ชื่อผู้ประสานงาน กลุ่มงาน วันนัดครั้งต่อไป)
Deliverable D: Q&A และ Objection Script ฉบับเต็ม (จาก Module 10.2-10.3)
Deliverable E: Document Checklist (จาก Module 10.5) พร้อมร่าง One-Pager และหนังสือแนะนำบริษัท (จาก Module 10.6)
Deliverable F: Risk Register (จาก Module 11) และ Compliance Gap Table (จาก Module 1.4)
Deliverable G: Roadmap 7 วัน / 30-60-90 วัน และ Decision Framework (จาก Module 12)
Deliverable H: Source List รวมทุกแหล่งอ้างอิงที่ใช้ แยกเป็น ทางการ (.go.th / ราชกิจจานุเบกษา / งานวิจัย) และไม่ทางการ (ข่าว / เพจ / ร้านค้า) พร้อมวันที่เข้าถึง
Deliverable I: Open Questions รายการคำถามที่คุณตอบไม่ได้จากการค้น และผู้ว่าจ้างต้องหาคำตอบเอง หรือควรถามเจ้าหน้าที่ในวันศุกร์ (นี่คือส่วนที่มีค่ามาก อย่าละเลย)

# QA CHECKLIST (ตรวจตัวเองก่อนส่ง)

- ทุกตัวเลขมีแหล่งอ้างอิงหรือถูกติดป้ายว่าเป็นค่าประมาณหรือไม่
- ทุกโครงการรัฐที่อ้างถึงถูกตรวจสอบว่ายังมีอยู่ในปีงบประมาณปัจจุบัน/ถัดไปหรือไม่ และระบุปี พ.ศ. ชัดเจน
- เลขที่กฎหมาย มาตรา และวงเงินตามระเบียบเป็นฉบับล่าสุดหรือไม่

## ส่วนที่ 2: หมายเหตุจากยุทธ (ไม่ต้องวางลง Gemini)

สิ่งที่ผมตั้งสมมติฐานไว้ในการร่าง และพี่นอร์ทควรยืนยัน:
1. ผมสมมติว่า "เกษตรจังหวัด" หมายถึงสำนักงานเกษตรจังหวัด สังกัดกรมส่งเสริมการเกษตร ถ้าที่จริงนัดกับสำนักงานเกษตรและสหกรณ์จังหวัด (สังกัดสำนักงานปลัดกระทรวง) หรือศูนย์วิจัยและพัฒนาการเกษตร (กรมวิชาการเกษตร) ให้แก้ชื่อหน่วยงานใน CONTEXT เพราะอำนาจหน้าที่ต่างกันมาก
2. ผมไม่ได้ใส่ตัวเลขวงเงินจัดซื้อ แต้มต่อ SME หรือวงเงินของขวัญ ป.ป.ช. ลงใน prompt โดยตรง เพราะตัวเลขเหล่านี้เปลี่ยนได้และผมไม่อยากให้ Gemini ยึดตัวเลขที่ผมให้แทนการค้นจริง prompt จึงสั่งให้มันไปตรวจฉบับล่าสุดเอง
3. ตัวชี้วัดคุณภาพที่สำคัญที่สุดของผลลัพธ์คือ Deliverable I (Open Questions) ถ้า Gemini ส่งรายงานที่ "ตอบได้ทุกอย่าง" โดยไม่มี open question เลย ให้สงสัยไว้ก่อนว่ามันแต่ง
